Bring Your Own Key

Spec2Tickets runs entirely on Atlassian Forge and calls Claude with your own Anthropic API key. No backend to host, no GPU, no Docker — and no data routed through our servers. Your AI usage stays under your own Anthropic account.

How it works

  1. Install & configure — add Spec2Tickets from the Marketplace, then paste your Anthropic API key and default project key in Settings (~5 minutes, no infrastructure).
  2. Generate — pick a Confluence spec page and click Generate. Claude produces a structured breakdown in ~60–150 seconds.
  3. Review in the editor — edit stories, acceptance criteria, dependencies, priority, story points, and labels inline.
  4. Push to Jira — one Epic, stories, subtasks, and blocks/is-blocked-by links, created in your project with one click.
